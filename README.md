# 喵喵跳一跳

一只毛绒手办小奶猫的平台跳跃小游戏，纯前端、零依赖，双击 `index.html` 就能玩。

## 两种玩法

- **高级版**（根目录）：7 只各有技能的猫、5 种天气、3 种模式、19 项成就、真实猫图渲染
- **简易版**（`simple/`）：早期轻量版，可从高级版首页底部一键互切

## 模式

| 模式 | 说明 |
|---|---|
| 自由跳 | 无限跳，天气一路变脸，能跳多远看脚法 |
| 竞速 | 限时 10–120 秒，失误扣时并回到当前平台 |
| 盲押 | 先盲按 N 次，再自动跳 N 块，弱化了操作、放大了运气 |

## 猫咪

每只猫的体型、重量、跳跃力、蓄力条长度、蓄力速度、腾空高度都不同，并且**跟随「猫咪技能」开关同步生效**——关掉技能时全部回归基准值，只比脚法。

| 猫 | 技能 |
|---|---|
| 波斯猫 | 从容蓄力（蓄力更慢更稳） |
| 狸花猫 | 猎手直觉（圈出落点中心） |
| 大橘猫 | 稳稳落地（边缘容错 +6） |
| 黑猫 | 九命护符（每局一次回击） |
| 奶牛猫 | 完美加分（Perfect 额外 +1） |
| 暹罗猫 | 灵巧（Perfect 判定圈 +5） |
| 小熊猫 | 尾巴回旋（擦边卷回，隐藏款） |

## 美术

猫咪素材由 AI 生成（九宫格，3D 手办 / 毛绒小奶猫质感），共有 **5 组姿态帧**：

`stand` 站立 / `crouch` 蹲伏蓄力 / `leap` 腾空收腿 / `fall` 下落 / `land` 落地压扁

游戏内按蓄力值、腾空高度、落地压缩量算**连续权重**，多帧同时叠加绘制，姿态切换是渐变而不是硬切。

精灵统一规格 360×300，内容高 276，脚底距画布底边 8px，所以只需把精灵底边中点对准平台坐标即可。

## 本地运行

直接双击 `index.html` 即可，不需要服务器。若要用浏览器调试工具，也可以：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

## 调试接口

控制台可用 `window.__NYA_DEBUG__`：

```js
__NYA_DEBUG__.snapshot()      // 当前状态快照（含 physics / chargeDuration / jumpRange）
__NYA_DEBUG__.startRun()      // 直接开局
__NYA_DEBUG__.setWeather('rain')  // 切天气
__NYA_DEBUG__.endRun()        // 结算
```

## 兼容性

- 纯静态，`file://` 直开可用
- 实测 320×568 / 390×844 / 768×1024 / 844×390 横屏
- 支持 `prefers-reduced-motion` 降级
